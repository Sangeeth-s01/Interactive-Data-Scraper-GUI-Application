# Interactive Data Scraper with GUI

## 📊 Project Overview
A Python-based desktop application for extracting, viewing, and exporting tabular data from websites. Designed for non-programmers with an intuitive GUI interface.

## 🎯 Features
- **Easy URL Input**: Simply paste any website URL
- **Automatic Table Detection**: Scans for HTML tables automatically
- **Multi-Table Support**: Handles pages with multiple tables
- **Interactive Display**: View data in scrollable table format
- **Export Options**: Save data as CSV or Excel files
- **Error Handling**: User-friendly error messages
- **No Coding Required**: Perfect for researchers, students, and analysts
